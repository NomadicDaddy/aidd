# Support

Thanks for using aidd. Here is where to go for help.

## Questions and discussion

For "how do I…", configuration help, backend setup, and general questions, use **GitHub
Discussions**. Search existing threads first; your question may already be answered.

Before asking, it's worth checking:

- **[docs/quickstart.md](docs/quickstart.md)** - install and first run.
- **[docs/reference/configuration.md](docs/reference/configuration.md)** - every config key.
- **[docs/reference/backends.md](docs/reference/backends.md)** - choosing and configuring a backend.
- **[docs/README.md](docs/README.md)** - the full documentation index.

## Bug reports

Open a **GitHub Issue**. A good report includes:

- aidd version (`bun run start -- --version`),
- platform (OS, PowerShell/Bun version),
- exact command or UI action,
- what you expected vs. what happened,
- relevant output from `logs/` (redact any secrets).

You can also file bug and feature reports from inside the web panel's project **Reports** tab.
These become tracked items in the project backlog. See
[docs/reference/project-reports.md](docs/reference/project-reports.md).

## Security issues

Do not report vulnerabilities through public issues. Follow [SECURITY.md](SECURITY.md).
