# Third-Party Notices

This is the attribution appendix to [`THIRD-PARTY-LICENSES.md`](./THIRD-PARTY-LICENSES.md).

The summary document says which licenses are involved. This one reproduces, for every package
in the **runtime closure** (the direct production dependencies and everything they pull in
transitively, which is what the compiled binaries actually bundle), the license text and any
`NOTICE` file that the package itself ships. That is what MIT, BSD, ISC, Apache-2.0 and OFL
each require a redistributor to pass on: not the name of the license, but the package's own
copyright line and terms.

Generated by `bun run licenses:generate`; do not edit by hand.

This appendix covers **274** third-party packages in the runtime closure.
