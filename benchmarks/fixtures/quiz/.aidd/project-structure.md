# Project structure

```
.
├── .aidd/
│   ├── spec.md                 # task brief
│   ├── project_structure.md    # this file
│   ├── questions.md            # the 4 quiz questions
│   └── responses/
│       └── quiz.md             # YOU WRITE this (combined answer)
└── src/
    ├── tools-index.ts          # read for Q1
    ├── config.ts               # read for Q2
    └── manifest.json           # read for Q3 and Q4
```

Answer order must match question order (Q1 → Q4). Write one response file at
`.aidd/responses/quiz.md` with four `## Q<n>` sections.
